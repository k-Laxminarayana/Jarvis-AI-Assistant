# 🤖 JARVIS AI Assistant

A voice-controlled AI desktop assistant built using Python.

## 🚀 Project Overview

JARVIS is a personal desktop assistant that allows users to interact with their computer using voice commands. It can perform common tasks such as opening websites and applications, searching the web, controlling YouTube, checking system information, taking screenshots, and performing desktop operations.

The project was developed progressively from V1 to V7.

## ✨ Key Features

- 🎤 Voice command recognition
- 🔊 Text-to-speech responses
- 🌐 Open websites using voice commands
- 🔎 Search the web
- 🎵 YouTube search and playback
- ⏯️ Play and pause media
- 📸 Take screenshots
- 📁 Open the Downloads folder
- 📂 Create folders using voice commands
- 🖱️ Mouse automation
- ⌨️ Keyboard automation
- 🔋 Check laptop battery status
- 🕐 Tell the time
- 📅 Tell the date
- 💻 Open desktop applications
- 🛑 Exit using voice commands

## 🧠 Development Journey

### JARVIS V1
Basic voice assistant functionality.

### JARVIS V2
Improved voice interaction and command handling.

### JARVIS V3
Added AI-powered responses and conversational capabilities.

### JARVIS V4
Added internet and web access.

### JARVIS V5
Added desktop and website control.

### JARVIS V6
Improved voice interaction, desktop commands, and AI responses.

### JARVIS V7
Added advanced desktop automation features including screenshots, battery information, folder operations, mouse and keyboard control, and media control.
